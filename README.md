# price-watch

Скрипт на Python, который следит за ценой товара на странице магазина и сообщает, когда она изменилась. Без внешних зависимостей.

## Как работает
1. Скачивает страницу по ссылке.
2. Достаёт цену по вашему регулярному выражению (одна группа с числом).
3. Сравнивает с прошлым значением из `prices.json` и печатает результат: первая цена, упала, выросла или не изменилась.

## Запуск
```
python price_watch.py https://example.com/item --pattern "data-price=\"([\d\s.,]+)\""
```
Для регулярного запуска подойдёт cron или GitHub Actions по расписанию.

## Тесты
```
python -m unittest -v
```

## Ограничения
Работает только со страницами, где цена есть в HTML без JavaScript, и не обходит защиту от ботов. Перед использованием проверьте правила сайта.

Учебный проект для портфолио. Python 3.9+.
